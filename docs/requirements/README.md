# Requirement baseline

`SkillCheck_Master_Specification.md` is the project requirement and product working baseline, including all 26 mandatory requirements and the optional item, plus the proposed shared GitHub collaboration workflow.

The PDF with suffix `v1.0-RC1_snapshot` is the previously approved presentation snapshot from before the repository workflow appendix. For the current version, read the Markdown or the Confluence page:

https://uce-group-webprogramming.atlassian.net/wiki/spaces/WPS/pages/295265

Any changes to teacher requirements or business rules need team approval, a versioned change, and reconciliation with Confluence.
