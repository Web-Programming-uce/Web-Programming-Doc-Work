# SkillCheck Agent Instructions

This file does not replace the product specification. **Read the entire** [`docs/requirements/SkillCheck_Master_Specification.md`](docs/requirements/SkillCheck_Master_Specification.md) **first**.

- Project requirements from the instructor (R01–R26) are mandatory. OPT-01 is optional.
- Use Java Spring Boot for the backend and React for the frontend; Node.js may power JS tooling but must not replace the Java backend.
- The core business rules are students/job seekers, 60–90 second oral challenges, Spanish Free / English demo Premium, 30/40/30 scoring, web/mobile/desktop and private user-aware retrieval.
- Respect the four required datastore categories in the architecture; do not invent deployed infrastructure.
- Treat current technical choices as a proposed baseline unless a specific ADR is formally approved.
- Follow [`CONTRIBUTING.md`](CONTRIBUTING.md), create an issue-linked branch/PR, and explain tests and document changes.
- Never commit secrets, private user data, audio, transcripts or production payment details.
- Never silently modify the Master Specification's requirements or resolve undefined `SDD, ODD` without instructor clarification.
- If an item is not implemented or tested, label it *planned* rather than *completed*.
